# Agent skills (playbooks)

Short, proven playbooks the agent reads before starting a task of that kind.
They are plain text on purpose: no build step, editable from a phone.

| File | Use it for |
| --- | --- |
| `deploy-vercel.md` | Shipping any repo to Vercel and proving it is live |
| `supabase-tasks.md` | SQL, RLS, cron, triggers and secrets in Supabase |
| `github-audit.md` | Full audit of every repository, CI, README, secrets |
| `freelance-profile.md` | Fiverr / Upwork / LinkedIn profile and gig optimisation |
| `outreach-and-leads.md` | Finding qualified leads and drafting compliant outreach |
| `client-delivery.md` | From enquiry to paid handover without disputes |

Rule: read the playbook, then verify the live state. A playbook is guidance, not proof.
