# Freelance profile playbook (Fiverr / Upwork / LinkedIn)

- Price against evidence, not hope: search the marketplace for the exact service, record the entry, median and top prices, then place just under the cluster that looks credible.
- Never compete in the $10-25 tier; buyers there expect rework and leave bad ratings.
- Gig title formula: "I will <result> <tech> <for whom>". Description: what is included, delivery time, what the buyer must send, and one proof link.
- Packages must escalate in scope, not just in price: basic = one thing done well, standard = the thing plus integration, premium = the whole job with deployment and handover.
- Every deliverable ends with a checkable artefact: live URL, repo, or a document. Screenshots are not proof.
- Upwork: an inactive profile goes private automatically. Logging in makes it public again. Freelancer Plus keeps it public while idle, but it is paid. Check `Settings → Profile visibility` if it stays private after login.
- Respond to enquiries within an hour; the first useful question beats a long pitch.
